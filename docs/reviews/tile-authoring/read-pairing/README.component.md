# Private current-read and form continuation

This fixes the a4 acquisition/read gap without changing a4, d8, the reviewed Root
coordinator or public formats. `adapter.mjs` composes one derived a4 bridge owner
and the actual fixed d8 encoded-byte owner/accepted 53d portable validator. Root's
actual frozen coordinator performs Stage and collection. No second executor,
coordinator, catalogue, raycaster, authoring allowance or history is introduced.

The follow-up is an explicit private continuation, not a claim that old 5a7 bytes
already supplied these seams. Original inputs stay under `vendor/`; `tools/pin.mjs`
records and reproduces the exact derivations. Root's coordinator is the explicitly
authorized immutable staged Git blob `5e061e9ef0ad643ad5b77b238f751734a4e6849f`,
SHA-256 `81e0d2ad2aaa52c01b9d1d3ed172b5bef951b4f8e7440c8218e591f787425db4`.
Its source is read by that fixed blob ID, never from Root's moving files.

## Usage card

1. Create `createC2ReadPairingAdapter(existingWorkbench, {bridgePorts, reader})`.
   Supply the same actual complete source owner and scoped ID allocator. Actual
   session/Core/native/meter preparation remains UNBOUND until its separate review;
   the byte adapter cannot turn metadata or cost DTOs into live readiness.
2. Mount this candidate's `component.mjs` with `adapter.binding` and Root's reviewed
   `attachTileAuthoringOverlayCoordinator`. Original 5a7 component/form bytes are
   preserved. The continuation changes only two imports and the selected-artwork
   default argument used while writing fields; layout and coordinator are borrowed.
   Load the unchanged stylesheet at
   `vendor/ui5a7/root/candidates/tile-authoring/ui/c2-runtime/styles.css`.
3. Select the real surface and exact artwork through the component/overlay ports.
   Call `await adapter.acquireSelected(adapter.getSnapshot(), {signal})` explicitly.
   It maps that actual issued UI read to its actual canonical bridge read and calls
   real d8. It checks the returned reference through d8's unchanged private read
   lookup. Discovery requests no PNG and creates no import/IDs.
4. The host owns each returned verified lease reference. Keep it in the existing
   resource lifetime/escrow; release or transfer it deliberately through
   `adapter.leaseOwner`. Refresh the panel/coordinator after acquisition. Fresh
   snapshots now preserve the pairing through an owned check inside the bridge's
   private read table. Exact captured source handle, original generation/context,
   selection, Basis and actual capability must remain current. Equal DTOs cannot
   replace that proof. No public arbitrary-capability adoption API exists.
5. The actual component passes its private dirty Set to `form-producer.mjs` through
   its existing `formFromFields` call. That intrinsic producer seeds individual
   untouched controls from exact `sharedArtworkDefaults(pin)`, creates one frozen
   Form, and stores its explicit graphic-field touches in a private WeakMap. The
   default adapter automatically borrows that same producer's readonly lookup.
   Copies, forged forms and another producer's forms return no provenance. No
   touched/ready/permission field is serialized. Updates remain explicit deltas
   preserving untouched radians, pivots and masks.
6. Stage uses the real Root coordinator's fresh reads and exactly one builder.
   The adapter checks the current read against the actual held acquisition read,
   calls the existing constructor with that original read for real d8's lookup,
   and forwards touch lookup to the actual current UI read. It validates before
   one ID allocation and collects one command with original Expected. Retained
   first mark is layers/add; absent builtin is selected import(s)/layers/add.
7. This is command DATA. It performs no prepare/Apply. The actual later session
   must start its one real attempt with that command's real original request ID,
   rerun exact Core/source work and pay actual costs. Query/byte work grants zero
   editing credit. Pending cancellation still needs the separately reviewed
   SAME-session helper; no eighth verb or review-token alias is introduced.

Canonical C0 agent JSONL commands remain independent of DOM intent. No canonical
schema, command/query parser, service or public export is changed. Private form
provenance applies only to this component's form-to-command constructor path.

Both status fields are computed from current readiness on every read. A ready
connection clears previous blocked/reload text; pending preparation and unknown
acceptance keep their original request/resource messages. No status string grants
permission or changes the actual gates.

Tests use real frozen Root Stage, continued 5a7 forms, a4/Core0597, Core53d, d8 and
the actual selected PNG. Source/session/action/preparation bindings are explicitly
protocol fixtures. These checks establish no native rendering, live Host Apply,
browser-wide authoring meter, WAL or consumer adoption. Exposed lease references
are never retired on source changes, unknown acceptance or adapter disposal.
There is no retained preview server or helper.

Accuracy favors exact original defaults and opaque source identity. Efficiency is
bounded owner/query work with one explicit acquisition (not a frame-rate claim).
Narrative preference is readable, faithful controls; that is a subjective UI
judgment. No donor design/profile or live release is changed.
