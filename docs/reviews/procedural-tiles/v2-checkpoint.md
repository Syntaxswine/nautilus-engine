## A: authored grammar and version fences

- Mixed self-contained v2 bundles retain complete original v1/v2 records, precise
  controls, anchors, templates, explicit recipe format versions and content hashes.
  V1 loads/saves/requirements/field/compile outputs delegate unchanged; no opening
  side effect upgrades a v1 source.
- Native records include editable Boolean DAG nodes/ordered difference, independent
  width stations and their metric, native section contours/vertices/materials,
  explicit frames/scales/caps, and retained stair count/rise/run/base/landing and
  lower-riser/first-tread/top semantics. No fitting, averaged widths or ramp
  substitution is performed. Cycles, missing operands/control IDs and invalid
  resource/shape data refuse.
- Layout annotations are only bounded label/description strings. Functional
  controls belong to closed typed fields. The private metadata validation view
  cannot be returned, hashed as native intent or compiled as native geometry.
- All v2 authored layouts remain saveable/unresolved, including v1-only intent
  wrapped in a v2 format. Resolved loads, live preparation, projections, interface
  matching, native cell derivation and requirements refuse. No fabricated handle
  or compiled inspector can become a committable v2 host plan.

## B: common render plans and independent exposure

- Sources are recompiled from accepted authored v1 data. Plan identity binds common
  world evaluator/canonical attributes, semantic floor/channel/layer/profiles,
  material/UV and explicit sampling policy. Incidental primitive/instance/owner/
  window/cosmetic IDs remain outside common identity. Real interior effects remain
  when they actually change an internal restriction.
- Every canonical external attribute and material interval is retained exactly;
  required non-grid material/contour events join the full schedule. Cut nodes (129),
  public port nodes (4,097), aggregate nodes (65,536), edges/bindings, analytic/root
  work, depth and events have explicit independent ceilings. No window is silently
  shrunk and no v1 limit is relaxed. A selected 16x16 one-metre workload produces
  17,952 base nodes; 32x32 refuses its 69,696 requirement.
- Analytic line/arc/cubic bounds include actual final-node deviation, both compound
  sides, arc encoding and floating guards. Independent dense original-curve tests
  cover D4 and translated quantization phase. Field-height restrictions are checked
  against independent accepted whole-field evaluation. Added public normals/tangents
  are explicitly interpolated without an analytic angular-error promise.
- Conservative contour brackets do not certify exact roots or topology. Their
  spatial bound includes parameter isolation plus actual returned-node deviation,
  encoding and floating contributions. Native polyline-distance scalar uncertainty
  remains separate. Conditioning/depth/root-work limits refuse explicitly.
- Zero evidence is independent of sampled sign and render refinement. Exact native
  edge corners/fade, complete control-domain containment and the actual native face
  direction are checked. A deflated polynomial collar enclosure proves inside or
  outside over the complete interval for all seeds, or returns unknown. Suppression
  is only conditionally eligible for actual compatible matched resident interfaces
  with both inside proofs. Missing sides, steps, conflicting floors/materials,
  incompatible directions and uncertainty retain each side's boundary geometry.
- Targeted development regressions first reproduced two false claims: an unsampled
  cubic leaving the field domain, and an inset border whose authoritative whole
  scalar varied independently of its normal-only evaluator. Both now refuse or
  use the proper whole source. Neither accepted v1 source behavior was changed.
