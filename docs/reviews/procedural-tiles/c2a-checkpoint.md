## Implemented and deliberately bounded

One optional typed layout composition record has kind/version, stable member/reservation references, union operation, named `level-rectangles-c2a` profile and a saved complete finish precedence (highest first). Group-free A/B source/digest behavior and generic unsupported native gates remain unchanged. Existing native v2 region controls can be evaluated only inside the explicit supported layout profile; unused future grammar remains retained/unrequested, never promoted.

One exact C1 arrangement accepts independently placed original rectangles using rational affine placement before construction. The core derives complete owner-labelled partitions, internal/external atomic interfaces and source port intervals without fitting or q1e6 gap closing. Every overlapping contributor survives; positive-area union is counted once; saved precedence chooses only cosmetic finish. Point sectors and complete void outer-neighbour associations are retained. Group root topology is distinct from the other complete-layout instances; empty group geometry does not claim an empty game world.

Whole-owner locks protect original source/bindings and exact visible coverage. Owner-specific finish uses a fresh request/source/owner-bound copy-on-write recipe, preserving all other controls, IDs, anchors, seeds and physical profiles; other shared users remain unchanged. No catalogue pruning. Group members have open full-profile ports; required/terminal obligations and external/full-side contacts retain their proofs or refuse. Composition certificates cover only the exact two named compatible primary rectangle reservations, not an owner pair or additional reservation.

Pure preparation validates complete old/candidate bundles, explicit direct owner changes, old/new semantic/spatial closure and one safe revision. It returns no partial candidate on refusal. Source/context-bound one-use retained handles use the same frozen v1 factory lifecycle logic with private resolver dispatch; one actual core authority, host CAS/final lease, host-owned history/checkpoint/journal and same-request unknown-outcome recovery. The Editor-shaped raw-map fixture is host conformance evidence, not a public Editor storage/history format.

Aggregate ceilings: 16 group members, 32 complete-profile/affected owners, no search, 128 old-plus-candidate original segments, 10,000,000 shared work, 2,048 partitions, 4,096 port bindings, 16,384 provenance links and 4,000,000 candidate artifact bytes, plus inherited input/bundle and C1 overlay arithmetic/topology ceilings. Canonical catalogue/shadow child sampling, including unused recipes, is precharged before child calls; exact arithmetic, serialization and output/provenance work stay shared. All caller limits only lower ceilings.

Final review also corrected malformed-instance validation ordering and bounded inherited diagnostic strings. Regressions verify malformed source/candidate containers cannot escape dispatch and unused catalogue samplers cannot hide outside the preparation budget.

Curved Boolean/field/general-line layout evaluation, varying-width ribbons, native sections/caps/solids, graded/mixed-level composition, stairs/ramps and physical material/width/height transitions remain unsupported. No C2a preview/query/support/navigation/fire/water/game readiness is advertised. ca285 remains a separate public-v1 surface provider; C2a does not synthesize pretend-v1 recipes for it.

## Design judgment and lifecycle

Accuracy favors exact labelled owner/source/port/contact contracts for adjacent and overlapping editing. Exact binary64 source-value geometry is not physical calibration. Efficiency favors one bounded core arrangement and shared work, with quadratic overlay and copy-on-write catalogue growth explicit; expectations and work-unit estimates are not measured device performance. Narrative preference for reusable parametric families/shared alignment and independent painterly finishes is subjective; legacy game profiles remain intact and richer game-specific simulation remains separate.

All source/test/build/install commands are foreground and complete. The private proof validates its exact task-prefixed temporary stage/consumer parent, removes it in finally and verifies absence. No preview server/browser/watcher, port or retained helper remains. No helper retirement daemon or unverified automatic enforcement is claimed. Root owns fixed review, later combined integration, and all public/presenter/Editor/game approvals.
