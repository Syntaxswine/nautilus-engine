# B2 native host decisions

The preferred implementation for Nautilus stack authoring is the existing retained session and public geometry provider, with the registered cosmetic finish adapter and explicit native floor table. The inherited v1 workshop and its three legacy skins remain a separate compatibility profile. Game adoption, solid-floor support, traversal and simulation are unbound.

**Accuracy.** The complete original three-layer map remains an unchanged raw JSON string. The first three floor references retain typed legacy-layer origins; twelve additional floors are authored tile floors. Uniform and nonuniform tables keep their literal metre elevations. Native vertex height ranges, complete owner/floor identities and material finish IDs are inspected from the real public provider. Selected-floor, overview and cutaway change visibility only. Cutaway captures an independent declared floor; later drawing-floor changes preserve it. All original line/arc/cubic controls remain source data, and actual rendered loops must still lie within a supplied reservation. Conservative source bounds are refusal discovery, not a proof of the rendered envelope.

**Efficiency.** Measured diagnostic counts in the actual source browser show 480 derived cells for a complete fifteen-floor 8 by 4 m stack and 960 during a two-view Finish review. Hidden floors retain their native geometries and their budget charge. The unchanged coordinator enforces two retained roots, 50,000 triangles and 1,024 derived cells across accepted, acquiring, candidate and unverified retiring records. A presenter owns one shared finish pool capped at 64 materials, and every native view owns its appearance leases. Appearance retirement precedes geometry retirement; both are attempted and attested. An unverified retirement remains charged and blocks another root. Borrowed host textures/materials and later material overrides survive view retirement. These are allocation observations and bounded-code properties; no frame-rate or physical-device performance claim is made.

**Narrative.** Brick pavers, stone flags, timber boards and poured concrete use the reviewed painterly building atlas and saved uint32 tone seed, preserving public canonical UVs and physical boundary profiles. This is the preferred appearance for the new shared authoring profile because it matches the existing building assets (subjective visual judgment). All v2 recipes, including the unused initial template, bind one of these four families. The three older skins remain available in the v1 workshop. No existing asset, donor file or game pin is repainted or changed.

The immutable finish binding is `nautilus-tile-finish-library@1`, content digest `5b4c25105568a1f99569dbb6bd2d6308c067bbb41763c4bd6bfddfa3552bc0e1`. The single borrowed atlas is `assets/buildings/painted-materials-v2.png`, SHA-256 `bbe33709a63362a13e509131c11f358d286b3d55ffcb86ca0ca1def4934ccdb2`, 2,558,637 bytes. The host hashes its actual fetched bytes before loading the texture, and supplies an exact opaque standard base material with no vertex colours, extra maps, alpha or custom shader. The public finish adapter owns its newly created appearance materials. Pool shutdown and verified lease release precede host resource disposal.

The new path route deliberately supports only new isolated level local paths and cosmetic Finish on unlocked unmanaged paths. Old/new possible-neighbour and semantic components span every floor and include extra reservations and reservation-free owners. A possibly interacting component refuses rather than inventing joins, crossings or geometry policy. For this bounded surface use case, that conservative refusal is preferable until another reviewed public interaction profile exists. Targeted geometry edits, ramps, grades, Boolean construction and path locking remain explicit refusals. Remote unrelated managed stacks stay intact.

The production UI is fixed to `8622c77234036d786474689f7e70671ecf01136b`. Only its three production files are relocated, with exact source/target hashes and literal import substitutions in `ui-source.json`; its fixture adapter is not runtime code. A small source form borrows the existing pure field codec and the sole session. There is one existing gesture owner, one actual five-label floor widget, one authority/journal/history and one retained consumer. Default v1 behavior remains unchanged. The only shared runtime hooks are the approved default-preserving rectangle projector and fenced v2 inspection action.

Source, built and offline-installed proofs use the actual declared stack/finish namespaces. The installed consumer records exact host import relocations to actual installed package files, checks provenance and archive hashes, and blocks checkout/provider fallbacks. No private planner copy or fixture adapter substitutes for a public implementation. Each browser helper has a bounded expiry, process identity/restart record and supported browser/server closure in `finally`.
