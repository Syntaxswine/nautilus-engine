# Combined equipment / close-combat checkpoint

The fixed implementation, review evidence and final gate receipts are supplied in the immutable Coder delivery packet. `registration.json` authenticates task source bytes and the approved art pin, current public exports/module closures/distributions, and exact accepted base preimages. It is read-only in normal checks. `sources.json` distinguishes original work, compatibility lineage and the two Architect-approved art commits.

Reproducible checks:

- Focused: `node --test tests/melee-core.test.mjs tests/melee-yard.test.mjs tests/native-melee-pose.test.mjs tests/native-melee-view.test.mjs tests/fantasy-equipment-art.test.mjs tests/fantasy-melee-registration.test.mjs`.
- Four engine gates: `npm run check`, `npm test`, `npm run test:upstream`, `npm run build` on the combined tree.
- Source entry: `node tools/fantasy-melee-entry.mjs --source`; bounded browser proof: `node tools/fantasy-melee-browser.mjs`. Its actual keyboard and 390px touch workflow, current contact/guard/cost results, typed attacks, interruption, all-item swaps, ranged visual state and mid-action reload are recorded under `artifacts/fantasy-melee-browser/`.
- Package proof: set `NAUTILUS_TYPESCRIPT` to an existing TypeScript 5.9.3 `lib/tsc.js`, then run `node tools/fantasy-melee-package-proof.mjs`. It packs, installs offline, authenticates every payload byte and executes real installed public JS/type imports with ten negative type controls. The report provides the isolated installed browser route. Use `NAUTILUS_MELEE_ROUTE`, `NAUTILUS_MELEE_OUTPUT` and `--quick` for its same keyboard/touch/reload workflow.
- Built fixture: `NAUTILUS_MELEE_ROUTE=/apps/test-ground/melee/`, `NAUTILUS_MELEE_OUTPUT=fantasy-melee-built`, `node tools/fantasy-melee-browser.mjs --built --quick`.

Browser helpers are hidden, exact-owner records with a real bounded expiry and `finally` cleanup. Their receipts must show exited browser/HTTP lifetimes and released ports before delivery; no diagnostic orphan cleanup is used. The Node compiler is read-only and is neither installed nor modified by the proof. Runtime, types, package and cleanup receipts in the final packet are immutable file-hash records, not claims about a moving checkout.

The selected-body/cone/height + wall-clearance contact is a documented conservative approximation. Initial balance is tunable, not a realism or FPS claim. No new ranged ballistics, weapon-mesh physics, donkey/crawl hand rig, consumer pin, Sites publication or held queue is part of this checkpoint. Architect owns review and merge; rollback removes this isolated fantasy successor and additions.
