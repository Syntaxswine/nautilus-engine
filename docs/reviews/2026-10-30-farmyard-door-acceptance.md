## Design choice and remaining scope

For **accuracy**, preserve the published Farmyard endpoint abstraction under its own profile. Prefer the native conservative clearance profile for new authored rooms; a source endpoint can accept a mid-arc/static obstruction that the native profile refuses. Both are bounded approximations, with no physical calibration claimed. For **efficiency**, the source-native visual is one 12-triangle mesh and headless core avoids renderer loading; relative scene CPU/FPS performance is unmeasured. For **narrative**, Farmyard's painted leaf, AP/readiness and guard reveal remain preferable for explicit compatibility; this is a game-specific judgment, not a universal policy.

Pairs, locks/keys/difficulty, door damage, upper layers, windows and reactive/fire behavior refuse before costs in this profile. Double doors need a separately versioned native coordinated-leaf profile, now queued. Native parts and the fixture prove bounded functional composition, not complete native-art editor authoring or production game adoption.
