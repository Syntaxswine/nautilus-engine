# White House model and furnishing collection

The artist's original White House collection is based on main `5f3627cd9fc4d95f15b7f1eefafdfb1d6034475f` on branch `codex/white-house`. It includes the residence, classic historic wings, colonnades, compact grounds, 46 adapted rooms, 463 interior placements and 51 independently reusable furnishing designs. The dedicated optional public entries, asset-only file URLs, static workbench and Building Library link are registered; consumer game behavior remains explicit.

The user requested editor-friendly proportions and painterly skins instead of dense physical surface detail. The estate uses a 1 m grid and six 2.12 m Z strata; residence occupied levels are 0, 1, 3 and 5, with double-height state/family rooms. The main residence is rounded to 48 × 24 m. The bathroom stall preserves the established 1 × 2 tile lot. Stairwell holes are present, and stair geometry connects the declared elevations, without claiming a movement/support binding.

The [usage card](../../../packages/white-house/README.md) contains public import examples, formats, units, resource ownership and the game-builder checklist. The [reference register](../../../art/white-house/references.json) distinguishes public tour plans/exteriors from the authored wing/family/service layouts. The [exact built-in image-generation prompt](../../../art/white-house/generation.json) records the new original skin. Reference pictures are research-only and excluded from the runtime and ZIP.

Fine damask, woodgrain, parquet, panel rosettes, gilding, drapery and rug decoration come from the shared painterly albedo atlas. No normal/displacement maps are used. Settled detailed source recipes retain bevels, flutes, glass drops and dense curves. The simplified derivative removes or reduces those after the forms are settled; measured per-model counts and the main model's roughly 77% triangle reduction are in the [manifest](../../../assets/white-house/manifest.json). These are geometry/file measurements, not city or physical-phone FPS evidence. An exterior-only model is supplied for cheaper views.
