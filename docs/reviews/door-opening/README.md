# Standard opening at an occupied threshold

Builder: Coder, Nautilus Engine. Base `09efd6580023ab4bca263fb9d7538858b0eaac1e`,
tree `ae0f33e03a3507c47ebbbe1007e0d20d0a2956a2`. The Architect owns final review,

The shared action already supplied its intended open/close state. Its reference
query ignored that state and rejected either direction whenever the opener or
another actor touched the full reserved swing envelope. Night Ledger's ordinary
near-threshold East pose is clear of the closed leaf but inside that envelope.

**Accuracy:** opening now ignores actor occupancy; closing retains its existing
occupancy check. Authored static/other-door clearance and traversal-body
reservations remain enforced. A newly opened leaf may overlap a body. Only that
body's initial contiguous overlap is exempt while it moves voluntarily; once
clear, subsequent segments sweep the leaf again. Other obstacles remain solid.
This is a deliberate interaction abstraction, not a physical hinged-door push.
No actor is relocated, and no timer, saved grace flag or resource change is used.
Exact saves may retain an open-leaf overlap so reload cannot create a trap.

**Efficiency:** code-based estimate: opening omits the existing actor scan;
escape derives from current bounds and adds at most the bounded returned walking
segments per initially overlapped leaf. There is no extra clock or per-frame
solver. No CPU/FPS measurement or performance advantage is claimed.

**Narrative:** for Night Ledger, opening from the normal doorway approach should
work immediately. Subjectively this is more readable than requiring a retreat
before opening. Voluntary escape avoids an unexpected shove. Recommendation:
use this shared standard behavior for this ground. The explicit source-exact
Farmyard adapter remains a separate compatibility profile; no donor adoption or
saved resource normalization is introduced.
