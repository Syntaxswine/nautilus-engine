## Prepared independently of the shared ABI

[`part-authoring-journal.js`](../../apps/editor/part-authoring-journal.js) coordinates opaque, already validated serialized authoring documents and resource-free compiler handles. It interprets no assembly/part fields and exposes no shared package API. The eventual editor host must validate/serialize/compile through the reviewed Coder entry before accepting a ticket.

- Edit, open, undo, redo and rebuild prepare without changing accepted text, history or compilation. Only acceptance commits. A whole assembly command will submit one serialized candidate; its child transforms and references remain the public command/compiler's responsibility.
- Tickets depend on document revision, preparation generation and a host-supplied compiler/definition/profile identity. A newer attempt, cancellation or context change makes old work stale. Equal authored revisions alone never establish scene compatibility.
- Failure retains accepted text, undo/redo and the previous compilation. A context change retains that previous handle for reference but marks it noncurrent. Rebuild updates the handle without inventing an authoring edit. Accepted open resets history; failed open does not.
- History enforces combined undo/redo entry and UTF-8 byte budgets on transfers as well as edits. It evicts oldest undo snapshots, then farthest redo snapshots. Defaults are editor-local and must be constrained to the public serializer's actual limits once pinned.

[`part-authoring-issues.js`](../../apps/editor/part-authoring-issues.js) prepares an inspector projection of named issues and opaque source targets. Clicking a current issue selects the source assembly/part and focuses its property. Stale or absent tokens cannot select anything. Play/export eligibility must come from the reviewed compiler/profile checks; a functional label grants neither. These fields and labels are private projection choices, subject to adaptation to the actual public diagnostics and UI binder. UI retains ownership of the shared readiness display/player.

Neither helper is mounted in the editor yet. There is no substitute parts schema, compiler, renderer, playable building or readiness service in this checkpoint.

## Public seams needed from Coder/UI

| Required contract | Why the editor needs it |
| --- | --- |
| Exact versioned definitions/instances, canonical serializer and public bounded command helpers | Discovery and supported inspector controls must come from real definitions. Translation, quarter turns, copy and deletion must transform all derived references together; IDs cannot be generated by decoding existing names. Copy needs fresh bounded IDs and a declared external-link policy. |
| Distinct accepted-incomplete authoring versus compilation/import failure | Incomplete work must remain editable and saveable. A failed attempt must preserve the accepted document, redo and preview. Specify whether an incomplete candidate has a valid authoring result with no replacement runtime result, and how diagnostics attach to it. |
| Compilation identity plus definition/profile/resource identity | Discard stale asynchronous results after definition changes even when authored revision is unchanged. Identify which accepted compiled snapshot a source map and preview represent. |
| Stable diagnostic codes, source maps and property paths | Project real instance/local-part/property targets into selection. Give a reason and remedy, including unresolved references and unsupported profiles. |
| UI binder preparation, staged swap, failure and disposal contract | Prepare the replacement scene before committing authoring/history, then perform a nonthrowing swap or a defined rollback. Resource acquisition failure must retain the live scene. The journal alone does not make an external renderer transaction atomic. |
| Authoring envelope versus runtime checkpoint/session lifecycle | Store authored definitions, instance IDs and initial settings. Define pause/restart/replace behavior while a stair traversal is active; undo must not silently rewrite a live session's geometry. Legacy export must return a preserving refusal with source paths. |
