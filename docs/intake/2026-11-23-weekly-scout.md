Each explicitly declared native collision triangle is clipped to the actor's vertical band and passed as a separate convex contact primitive. This preserves apertures inside a compound mesh. The complete reachable envelope includes secondary tangent contacts. The host validates accepted segments against actual solids, furniture, world edges, support, headroom and step height. Support-edge stations catch a narrow gap between otherwise supported endpoints. Accepted polyline distance and height drive movement and pouring. The placement correction transforms source-local collision vertices with the same rigid transform as their rendered parts and clips surviving fragments into matching bounds.

- **Accuracy.** Prefer this optional binding for source-declared native solids with doorway, curved or compound geometry where a whole-mesh envelope overstates occupied space. It retains separate triangle fragments and actual support heights. The bounded upright-disc model still simplifies body shape. Use the established source-cell blocking policy for authored tactical foliage. This proposal concerns native solid geometry and must retain that accepted foliage policy.
- **Efficiency.** By code inspection, clipping and testing candidate triangles costs more than a single box query. The donor reuses the current broad-phase native index, limits proposals to 8,192 primitives and keeps the kernel's bounded four-contact policy. There is no new scout CPU benchmark for this adapter. Prefer a restricted native-geometry profile and measure representative triangles, doors and multiple actors before broad adoption.

H15's published improvement also includes a wider portal and changed furnishings. Its whole-route result cannot isolate the adapter's contribution. The focused native-query and placement controls supply the reusable evidence.

The host retains floor identity, body dimensions, step/headroom policy, world/query revisions and atomic accepted movement/resource commits. Keep the original stop profile and existing saves usable, with an explicit profile choice and restore behavior for new adopters. The donor adapter's dynamic support, stair and furniture decisions remain host bindings.
