## TB-7ba7487-finite-heat · P1 · Proposed

**Scope.** A small optional headless ground-to-structure heat transfer profile for Tinderbox and other games that need fuel-driven fire. Tinderbox master contains the reviewed heat commit `91a9ad19ef8ae4575c3f2b9e8d68b95cee1729d3`. The core source is `src/simulation/{config.js,field.js,cottage-fire.js,index.js}`. `housing-fire.js` and the pinned floor-fire tests are a separate reference for damage to sections and collider retirement. [Published heat source and results](https://github.com/Syntaxswine/tinderbox/blob/7ba748719f848d3e41020d3f6e7d4ecbac378264/docs/engineering/fire-exposure.md)

- **Accuracy.** Prefer Tinderbox's separate source output, finite fuel, receiver coupling, cooling and threshold when spread itself matters. The previous receiver-limited formula could give grass and gas the same ignition time. Clear probes and blocked masonry controls make the difference causal. The current exchange is local and plan-view, and the heat units are tuned for the game. Share the output/receiver model with hosts that need it. Keep AFT and Farmyard's turn-based burn/panic policy for short tactical hazards. [Existing Nautilus fire comparison](../reviews/2026-10-28-design-tradeoffs.md)
- **Efficiency.** Prefer the turn counter for ordinary tactical burn status. The richer option scans the field, checks neighbors of burning cells and samples two fixed outward contacts per eligible low-wall site. These are code-based workload estimates. Start with a small bounded scene and measure the hot path before indexing or scheduling more work.
- **Narrative.** Subjectively, the finite model suits Tinderbox because the player can see a small mistake burn out and a sustained fuel trail set a wall alight. AFT and Farmyard can keep a clear danger timer where there is no fuel-management decision.

**Suggested work.** Coder owns a fixed-step profile with material IDs, a shared solid/contact query, explicit world seconds and stable ignition/burnout events. Reuse the installed world/part geometry boundary at metre scale. Keep renderer skins, collision, heat and gameplay saves separate, including game-owned HP, time scaling and resources. Specify replayable heat/fuel state and once-only transitions before adding live section retirement. Artist/UI can use an existing cottage and the existing tool controls for the fixture. The published facing/first-contact correction is useful conformance evidence for an ignition source, and can reuse the earlier contextual input assignment. **Effort estimate** 2–4 builder days for the first bounded proof.

**Accept when.** On identical geometry, grass and a short spill heat and cool below ignition, a longer spill catches, a screen blocks contact, and burning wood can ignite existing ground fuel without creating fuel. Check order, pause, restart and deterministic reload. If section retirement is added, check independent timings and query/collider retirement for only the cleared section. Any wind or presentation extension follows its own reviewed dependency.

**Suggested work and acceptance.** Artist and Coder can fit the light as an optional presentation provider after the shared attachment/query boundary is chosen.
