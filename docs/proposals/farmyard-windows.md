## Native geometry, placement and stable identity

Local source axes are `[X,Y,Z]`: span along X, floor at Y=0, glass centre plane Z=0, front +Z. World query coordinates are `{x,y,h}` in metres, with horizontal x/y and vertical h. A placement rotates around model +Y by 0/90/180/270 degrees:

`world.x = placement.x + cos(r)*local.X + sin(r)*local.Z`

`world.y = placement.y - sin(r)*local.X + cos(r)*local.Z`, `world.h = local.Y`.

Source `z` is a layer and must be zero for this profile. Do not use a floor index as metres. Horizontal 0/180-degree placements replace s-edges; 90/270-degree placements replace e-edges. A wide authoring placement starts at the selected cell, covering its whole width. Edge alignment derives from `start = along - (width-1)/2` and `across-.5`, both integers.

| Quantity | Native fact |
| --- | --- |
| Framed preset assembly | Width 1/2/3 m, height 2 m. Full glass 0.055–1.945 m; waist glass 0.90–1.945 m. |
| Borderless presets | Three separate 1/2/3 m IDs, height 2.12 m, one `r0c0`, no posts/frames/mullions/caps. |
| Resizable template | Explicit saved `{width,height}` in metres; whole-metre width 1–240, positive finite/float-buffer-representable height. There is no source storey-count cap. A host's stricter world/budget limit must refuse explicitly, never shrink. |
| Dimensions vs storeys | Width 20, height 5 metres is 20×5 m. Five storeys explicitly converts at 2.12 m/storey, with source 12-significant-digit rounding, to 20×10.6 m. The resulting whole sheet still has one pane. |
| Members | Frame depth .20 m; wall thickness .16 m; glass .008 m; post .055 m; mullion .035 m. Joins halve shared post width without changing pane IDs. |
| Existing decorative bay | A two-metre wall bay with .5 m flanks and a 1 m opening is distinct from a two-metre-wide glazed assembly. Keep its original identity/scale. |

Preserve the full 1–96-character source placement ID and local `r{row}c{column}` pane ID. Use an explicit tuple `{sceneId,placementId,paneId}`; do not key damage solely by definition or by an ambiguous concatenation. Structural member IDs remain `frame.left`, `frame.right`, `frame.sill`, `frame.head`, `mullion.v*`, `mullion.h*`, `wall.lower`; walking reservation is `passage` / role `window-passage`. Glass may have no source role, represented as null in query facts rather than undefined.

Reuse existing parts identity grammar for **visual handles** through an explicit `engineInstanceId` binding and `partIdentity(engineInstanceId,'visual','pane:'+paneId)`. The fixture retains a long original placement ID and supplies a separate short binding key. Existing parts keys allow only 24-character instance / 32-character local part IDs; never silently shorten/hash/substitute a source identity. These handles do not extend the closed parts-v1 kind set or certify a compiled playable window. The current parts runtime's mover/history remains retained; this component owns no mover.

Placement/content is immutable within an active pane-state epoch. Definition digest covers the fixed source version, dimensions, joins and exact pane/member bounds. A live resize/preset/topology change needs an explicit new content epoch or reviewed migration. Copy gets a fresh placement ID and intact panes; damage/impact/effect receipts are not copied. Editor undo/redo affects the authoring document as one command and does not replay gameplay effects. Underlay must retain original covered edge kinds and only restore where no replacement exists.

## Proposed headless API and owned data

The following names/shapes are the decision requested from Root, not callable exports yet.

| API | Proposed behavior |
| --- | --- |
| `compileWindowPlacements(input,{definitions,world,edgeFacts})` | Strict plain-data preparation; fixed content/geometry digests, immutable placement/part/source maps, complete covered-edge set and member colliders. Validate uniqueness/alignment/bounds/semantic conflicts before replacing a prepared scene. |
| `createWindowState(compiled,{id,broken})` | State v1 bound to exact compiled content and profile, full pane-state projection and a complete bounded command journal. Empty legacy broken map means intact only under the explicit legacy profile, not after losing a saved field. |
| `queryWindowSegment(compiled,state,{purpose,from,to})` | Pure current member intervals/nearest candidates with placement/part/pane tuple, geometry revision/digest, point, normal and kind/role. Host composes these with its complete world/actor query; a window-only hit is not automatically the nearest world hit. |
| `stageConfirmedWindowImpact(compiled,state,request)` | Pure stage of a **host-confirmed** impact against current geometry/content. Returns copied candidate, expected tokens, stable receipt and deferred effect observation. No roll, AP/ammo debit, damage, visibility scheduling or live write. |
| `openWindowState` / `serializeWindowState` | Validate the entire prospective state/journal/content before live replacement. Restore poses/broken masks without cosmetic event replay. |
| `windowRequirements` / `assertWindowCompatible` | Derive requirements from actual authored/live content. A named game, opaque JSON or decorative window entry does not imply implementation. |
| Optional definition/presentation provider | Native source specs and later host-Three material/mesh binding, keyed to the same placement/pane/member IDs. Present committed state and once-only receipts; no hit decisions in shaders/animation/audio callbacks. |

The fixture's proposed packet is `{version:1,id,sceneId,stateId,expectedRevision,placementId,partId,paneId,definitionDigest,confirmation:{hostCommandId,round,geometryRevision,cause,point,direction}}`. `paneId` is null for a structural hit. Scene/state identity prevents a request from being reused against another scene with coincident placement names/revisions. A `confirmed:true` client boolean would not confer authority: only the host's trusted combat commit path creates the confirmation, after a successful roll and nearest-world impact selection and before its outer atomic write. A miss/preview never calls the stage operation.

State contains IDs/version/profile/content reference, current broken masks and complete durable accepted-impact receipts. Proposed limits retain source 1,024 placements, at most six panes/eight solid members plus one reservation per placement (code estimate: ≤6,144 panes / 15,360 colliders), and a separately declared 128-impact journal with explicit refusal at capacity. Adopt the existing 8 MB / 500,000-node / depth-24 transaction budget provisionally; Root must confirm it against the complete composed save. No durable ID eviction or clock-based expiry. The source cosmetic 128-event tail is a different contract.

Frame/sill/mullion hits stop the selected source shot without breaking glass; their accepted host command still needs durable deduplication. A glass hit breaks one identified pane and stops that round. The next round re-queries the **prospective** current geometry through the hole. The host may stage successive round IDs within its existing outer burst transaction; do not precompute every round against old glass or spend ammunition twice. Repair, new glass, penetration/material energy and topology migration are separate future profiles.

The test-only fixture demonstrates first glass at clear A, then clear B after A breaks, and distinct mullion/sill/lower-wall/pane rays through a waist grid. A framed sill's deeper footprint can be the first walking blocker even at standing eye height: do not substitute the sight filter for movement. It also demonstrates all four rotations, the tall one-pane sheet, independent identical instances, joined post widths and saved masks with no old events.

Use exact source EPS/endpoint policy where selected: `confirmedImpact` accepts obstacle entry only when `t > EPS` and chooses a strictly earlier entry, preserving source member order on ties. Explicitly expose/reject an embedded projectile origin under the initial bounded host profile rather than relocating an actor or silently changing this behavior. Broadphase acceleration may overselect candidates but must not omit native members or stretch a short member vertically. Full actor collision/navigation and guard tactics remain retained host services.

Covered legacy edges must be removed and adjacent 1.12 m legacy wall overhang clipped to the half-cell seam using actual edge provenance. Merely drawing transparent glass in front of an existing opaque wall fails the contract. Do not apply source clipping heuristics to arbitrary native/curved walls without a reviewed provider. Offscreen/residency changes never retire authoritative pane state or query geometry.

## Atomic host connection, persistence and lifecycle

Reuse the reviewed host transaction **contract** and ownership/reentry/recovery fixtures from doors, without constructing its mover runtime or widening its named profile. The current parts runtime and item transaction helper are domain-specific; a minimal shared lease/CAS/receipt helper extraction, if needed, is implementation work for Root's approved scope. Avoid another per-scene handler or independently committing combat system.

1. The host supplies exact content and a complete geometry/world identity, then prepares the immutable window context once. Editor can retain incomplete authoring, but play readiness/compilation must report missing bindings and preserve the last accepted scene.
2. Preview/query is read-only. The existing weapon/impact system owns rolls, stock/AP, confirmed target choice, ordering and any actor consequences. It stages the pane change alongside those records using original typed host/round IDs.
3. In one synchronous transaction compare complete expected state, relevant context/geometry and host tokens; check a final `candidate.canCommit()` fence and commit all records. Copy read loans/CAS arguments/results; reject reentry; stop later publication on dispose/staleness; keep acknowledged actions committed if a view fails. Unknown acknowledgements preserve original IDs and recover from authoritative receipts, as in the reviewed connection correction.
4. Invalidate geometry/routes once and publish the same current member data to walking, sight, projectile/flame and presentation. Host owns post-impact fog/guard/turn refresh. Do not reuse door debit/contact ordering or silently enable the released grenade profile's refused windows.
5. Validate a complete prospective save, definition/content digests, pane references, journal and retained host data before replacing a session. A source projection preserves placement IDs/dimensions/joins/underlay, broken panes and source sequence. Loading/adopting neither heals/refills/relocates nor replays shatter/audio. Changing origin/content requires explicit compatible migration.
6. Restore visual pane masks from current authority. Register cosmetic observation once at the current cursor, so revisit/reload/culling cannot play old breaks. Short-lived effects can be dropped; authoritative receipts cannot. Dispose owned geometry/materials/textures/effect meshes/audio voices/aborts, fence late loads and leave borrowed renderer/clock/persistence alive.

Required host service proposals are `fixed-window-definitions-v1`, `complete-window-query-composition-v1`, `confirmed-impact-authority-v1`, `atomic-window-context-commit-v1`, `window-geometry-invalidation-v1`, `complete-window-save-staging-v1`. A later presentation capability is separately negotiated. These are service responsibilities for review, not claims in the current engine manifest.

## Explicit refusals and Editor integration findings

- Refuse non-ground layers, arbitrary rotations/tilts/curved panes, incomplete or overlapping spans, unsupported/malformed IDs/dimensions/content, missing template dimensions and unknown/broken pane references before a live commit. Framed resizing is unsupported; positive-finite renderer dimensions do not imply fractional sector widths.
- Derive pane requirements from actual content. Unknown consumers, legacy block export or generation paths without reference remapping must preserve the document and return `WINDOW_LEGACY_EXPORT_REFUSED` / `UNSUPPORTED_WINDOW_CONSUMER`; opaque extension retention alone cannot pass. No fields are inserted into closed map/parts/world-v1 schemas implicitly.
- Classify occupied edges semantically across **all** door families, including `jail-door-closed` / `jail-door-open` and lock references. The source `startsWith('door')` guard is insufficient. Return `WINDOW_DOOR_CONFLICT` atomically without clearing undo/redo or leaving an orphaned lock.
- Refuse preview/miss/untrusted confirmations, changed geometry/content, unsupported embedded origins, stale revisions and changed reused IDs. Keep exact retries quiet after intervening actions/load. Validate aggregate saves before acceptance; refuse a full durable journal instead of evicting IDs.
- No new guard AI, cast/rules/stock authority, upper-floor/vault/climb route, heat/fire cracking, glass repair or ordered reactive grenade/tank blast cascade in the initial impact scope. Source blast behavior is audited evidence for a later explicit profile; current released planar grenades and Farmyard doors continue their existing window refusals until composed support is deliberately approved.
- Disable frame-finish controls for borderless sheets while retaining source appearance metadata. Require shared-Three readiness before rendering. Shader/material, tall-shard receiving-floor, audio, phone/input/history/cross-realm buffers, late loading and section ownership acceptance follow the later public provider; this data checkpoint does not certify them.
