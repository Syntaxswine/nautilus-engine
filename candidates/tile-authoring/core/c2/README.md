## Supported operations and refusals

content.import accepts closed, self-contained dependency packs of supported local rectangle definitions, empty-default presets and PNG Artwork records. Same id/revision/digest is immutable; differing content refuses. Full blob descriptors, frame bounds, exact entry/hash/length/media name, complete required profile union and all notices are retained. This phase checks descriptor closure; actual bytes/decoder readiness come from owned preparations. Unique encoded requirements stay within64MiB.

surface.layers establishes the exact current owner/surface/floor binding and up to8 ordered layers. Deleting layers must name exactly every removed mark. An empty layer list removes the binding after explicit mark deletion. decoration.add requires a fresh ID/revision1 and an existing layer. decoration.update requires same ID, exact old revision and next revision; changing owner/surface/floor/binding refuses. decoration.remove names existing marks explicitly. Locked owners refuse edits. All operation IDs are unique; a late failure preserves the entire source.

Masks use all-surface or sorted, non-overlapping finite authored-grid spans bound to exact grid id/version/digest, at most4096 cells per mask. Stamps clamp; detail repeats. Finite transforms preserve saved pivots, tint and opacity. All untouched library/recipe/owner/chunk values survive. Grouping, group mutation, reanchor and owner deletion refuse as Stage C. Geometry/default placement is outside Plan2; placement-with-marks awaits an accepted combined route. Real-byte pack and capture producers belong to the separate Stage B checkpoint.
