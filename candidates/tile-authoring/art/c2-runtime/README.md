# Private C2 painterly appearance runtime

This checkpoint supplies artist-owned native resources and sampling for reusable tile surfaces. It is a private candidate, outside every package profile and the editor. The initial route changes appearance on an unchanged complete tile bundle. Geometry-plus-appearance placement, public discovery, editor controls, tickets, WAL/CAS and consumer adoption remain separate coordinated work.

The exact dependency is accepted decoder proof a66c78332c90fda33c16ffa7518a358b60249169, based on Main 8184f06aa587542b026352a739f3766d1794c4fe. inputs.json preserves source hashes, adaptations and the reference-only capture ABI inventory. The pending normalized-limits/finalBindUpperBound amendments need a newly approved exact manifest before formal DTO source-binding. No moving peer runtime is imported. Core f32 is not an accepted dependency.

## Supported artist behavior

- The exact original 30 artwork records and defaults: 29 finite stamps and one repeating detail. Both original PNGs and their frame geometry, alpha floors, notices and default transforms remain unchanged.
- Source-grid sparse bins, explicit masks and deterministic layer/mark order. Public tile art clips the presentation; marks add no triangles and use no transient-cell anchors.
- Top-left image coordinates and noncentral pivots, current owner D4 once, original surface origin/basis, and native XYh to render XhY once. Raw alpha thresholding precedes manual filtering. Filtering and composition use linear premultiplied color; layer opacity applies after its marks compose.
- Borrowed shared Three and an ordinary Standard base. Each owned appearance material contains one fresh combined hook: the byte-exact old finish map kernel, followed by sparse artwork. No old hook is chained or mutated; the old base guard and cache-key behavior are unchanged.
- Each changed or cleared appearance receives a separately constructed public-provider base view with its actual complete geometry. An encoded-only import may retain the actual source view only when the drawn appearance is unchanged. There is no tileRepair route or assumed geometry sharing.

The initial managed-surface profile remains the accepted owner-local, horizontal named rectangle. The sampler has additional frozen D4 and rotated-basis witnesses; these do not expand the Core authoring grammar.

## Live ownership

The private modules are direct internal imports; no package entry or registry is added. The host supplies shared Three, tiles, a borrowed base atlas/material, complete live enumeration of other appearance materials, an actual renderer context epoch, retained source/history resources and currentness/cancellation callbacks.

PhysicalMemory retains actual ArrayBuffer identities, native reservations and distinct reference IDs. Equal bytes or hashes never merge independent stores. All acquiring and unverified-retiring allocations remain charged. A known sampled original image has its full RGBA8 byte floor even without a decoded-observation ID. Recent diagnostic events are bounded; truncating that diagnostic tail never removes physical rows, references or debt.

OriginalImagePool retains encoded snapshots and uses one owned 6 MiB output buffer serially for both originals. It detaches the caller pixel view only after upload completion. Native textures remain distinct, with live context/epoch identities. Source, target, history, redo, pending and export owners acquire separate leases; a reason string alone grants no retention or authority.

AppearanceDataAtlas owns one 256 x 64 RGBA32F page and distinct source/candidate ranges. Its CPU and native rows record each real lease. A caller-provided verified boolean cannot free bound ranges. PublicViewOwner retains all owned roots, geometry buffers, marks and materials after an unverified disposal. Default candidate retirement intentionally cannot open capacity for another candidate.

The optional createObservedWebGL2Context observes actual buffer storage and update counts in a NEW owned context. It never patches a user/shared renderer. It provides actual source/candidate WebGLBuffer identity evidence; it does not attest opaque driver upload staging.

## Strict admission and current limitations

WebGLTextureOwner requires a live native staging-bound owner for strict upload. Ordinary JavaScript WebGL observations cannot prove an upper bound for opaque native copies. Diagnostic probes explicitly permit rendering with retained one-image-copy reservations and report nativeUploadBoundsProven:false. Those amounts are diagnostic reservations, not a proven native quota. gl.finish proves completion of reads from the caller's buffer; it does not retire opaque staging.

The old public finish pool exposes counts rather than complete material identities. A real composition must supply the complete live material owner. The artist provider does not silently accept a count-only replacement.

createAppearanceOwner supplies intrinsic private source/preparation handles and actual resource observations. Its data is expressly NOT a SourceCapture/PreparedCapture, an authority check or commit permission. formalABIAdmittable is always false. The Core producer must assemble and validate the finally approved closed DTO from live owners, and the editor must supply preserved-world checks, warm/admit actual GPU state, capacity binding, ticket/full WAL, guarded Review and final commit/recovery. A newly approved manifest is required before pairing those seams. Unknown outcomes freeze disposal and retain the resource union.

There is no public/Host/UI integration, save codec, undo/redo behavior, phone performance result or native-copy quota acceptance in this checkpoint.

They save restart records, failure evidence and cleanup receipts under unique ignored artifact directories. They never attach to user browsers or retain a service.
