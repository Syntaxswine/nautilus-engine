# Implemented private method packet

These are trusted, constructor-bound implementation hooks. They are not a new JSON API, a second journal/authority, or proof that an actual meter/renderer is paired. Every method is required when opting in; missing methods refuse `C2_HOST_UNBOUND`. `assertPaired` must authenticate the actual backends/coverage and continued owner. Protocol fixtures do not satisfy production pairing.

Actual source: `runtime/apps/editor/smart-tile/session.js`. Existing adopted sources remain untouched. Default profile has no `c2Host` or `c2PhasePorts`.
