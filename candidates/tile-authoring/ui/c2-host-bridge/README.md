# Private C2 Host connector

This bounded candidate supplies an issued finite C2Read, explicit source selection
and canonical command DATA for the accepted overlay UI. It borrows the existing
workbench, seven-method service, drawing-floor/input/history and resource owners.
It changes no public entry, C1 panel, schema, consumer pin or normal build.

Use `createC2HostBridge(existingWorkbench, ports)` from `bridge.mjs`. The API is in
`bridge.d.mts`; minimal owner contracts and the query/preparation distinction are
in `ports.d.ts` and `ports.md`. Dispose the bridge to remove its one subscription;
borrowed services and resources stay with their existing owners.

## Usage card for the next integrator

1. Supply the SAME existing workbench and a `SourceReadOwner` paired to its actual
   complete current v3 reads. Preserve original sourceJSON, all 15 native floor
   elevations, opaque properties, definitions, Pins, decorations and descriptors.
   Borrow the actual drawing floor; do not choose the first floor by inference.
2. Create the accepted d8 byte owner with `bridge.sourceOwner`, actual public
   artwork metadata, the existing byte reader and reviewed portable validator.
   Pair that owner ONCE before exposing reads. The host acquires/retains the
   explicitly selected lease; `selectedBytesBinding.resolve` is a non-owning
   lookup. Discovery and selection adopt no record and request no PNG. Preserve
   the exact issued-read/acquisition pair: d8's private lookup does not recognize
   a fresh read merely because its Basis, Pin and cached capability compare equal.
   Root must preserve that pair or explicitly acquire through the existing owner;
   the connector cannot retag a capability or copy the owner's private lookup.
3. Send numeric/list selections through `overlayPorts.selectExisting`. Canvas
   selection requires the SAME input owner's resolved hit; no raycaster is made.
   UI labels are descriptive; exact source identifiers stay in finite data.
4. Seed first/add controls from `sharedArtworkDefaults(exactPin)`. Pair actual
   touched-field provenance with the exact form. Defaults come from the public
   original 30-record namespace, never a latest alias or reconstructed catalogue.
5. Call `constructOverlayCommand(actualIssuedRead, form)`. It reruns bounded
   Core 0597 inspection, validates intent/source/selected prefix, then allocates
   IDs once through the scoped existing owner. It returns one command with original
   Expected. A builtin first mark has import(s), layers, add; retained first mark
   has layers, add. A copied/read-refreshed Basis is refused.
6. Treat that output as DATA. Do not execute it because construction succeeded.
   Root must attach the accepted C2 coordinator to the SAME C1 service and bind
   reviewed actual preparation. That later `session.prepare`, with the real
   original request ID, starts ONE authoring attempt before source/history work
   and reruns/binds exact source/command while paying actual work. Query work is
   never editing credit. The actual Core/session/native/meter port remains UNBOUND.
7. Pending Cancel/ESC requires the SAME-session owned preparation cancellation
   helper. Without it Cancel is unavailable. Unknown acceptance retains resources
   and original ID for recovery. Do not use service review-token cancellation or
   draft discard as a pending-prepare substitute.

## Integration checklist

- [ ] Root supplies the reviewed C1 attachment; no second coordinator or service.
- [ ] Actual source/read owner, scoped ID allocator and input touch seeding paired.
- [ ] Actual selected d8 byte capability; no DTO grants native/editing readiness.
- [ ] Actual reviewed session Core 0597-derived preparation reruns exact work.
- [ ] One real attempt, one original request, one history/WAL path; no query coupon.
- [ ] Actual native provider, browser-wide meter and resource escrow reviewed.
- [ ] Actual pending cancellation/ESC, unknown recovery and cleanup independently checked.
- [ ] Root promotion rewrites the explicit vendor entry relocations from fixed pins.
- [ ] Native/UI integration and visual review performed after those real bindings.

Unsupported geometry, locks, groups, incomplete sources and stale/copy/foreign
reads produce preserving refusals. Update preserves untouched fields and exact
revision; removed layers must explicitly name their complete removed marks.

Focused controls are component/data proof, including the real selected PNG,
accepted portable/byte APIs and the actual C1 service with an explicitly synthetic
session. The test-only portable closure is byte-identical to accepted 53d; the
provenance checker verifies its entire static closure. These controls establish
no Host Apply, native appearance, browser-wide editing meter or WAL adoption. No
preview server or other retained helper is needed for this headless connector.

Recommendation for this editor: retain exact source frames/defaults and explicit
owner bindings. Accuracy is source fidelity, not a new physical model. Efficiency
is bounded query work (code-based limit, not a frame-rate measurement). Explicit
selection and preserving refusals make author intent legible (subjective UI
judgment). No donor design/profile is changed by this connector.

and `node candidates/tile-authoring/ui/c2-host-bridge/tools/verify.mjs`, then the
repository checks required by AGENTS.md. Provenance is in `source.json` and
`vendor/source.json`; original upstream bytes remain separate from adapters.
