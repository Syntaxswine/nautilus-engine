# Private read and constructor ports

`CompleteRead` names the existing complete v3 document and presentation.
`SourceReadOwner` recognizes that actual workbench read and its existing opaque
source handle. The bridge privately recognizes each issued C2Read and its exact
Basis by WeakMap. Copies, foreign reads and equal digest DTOs cannot authorize
construction. Fixed 057 and accepted 5a7 remain unchanged.

Pre-command inspection uses accepted Core 0597's bounded pure target producer on
that recognized current source. It validates fields, selection, source frame/grid
and selected complete dependency prefix before allocating the complete ID set
once. The result is command DATA ONLY: no authoring attempt, ticket, WAL,
provisional request ID, native readiness or editing credit. Query work is not a
cost coupon. The synchronous ID callback receives the actual source and counts.

Actual preparation happens later through the SAME existing service/session using
the command's original real request ID. It must start ONE real authoring attempt
before source/history work, rerun and bind exact source/command through the reviewed
Core 0597-derived path and pay the actual work within that owner. It cannot reuse
inspection credit or gain a second editing allowance. The real session/Core/native/
meter path remains UNBOUND. `PreparationBinding` observes that actual reviewed
connection; it starts nothing. A declaration, profile or copied cost DTO cannot
enable it. Root owns the protected C1 attachment and final composition.

First/add forms lack touched-field provenance. The actual input owner must
recognize the exact form and explicit touched fields. Start from exact public
`sharedArtworkDefaults(pin)` and apply only those fields. An untouched UI
placeholder cannot be inferred to be an edit. This intent port grants no authority.
Updates already have explicit changes and preserve untouched radians, pivots,
masks, target identities and exact original artwork revisions.

The accepted d8 runtime is imported from fixed Git objects. Its encoded-byte
preflight reports `editingWorkCredit: 0`; native preparation and the browser-wide
editing meter remain UNBOUND. The bridge borrows an explicitly acquired selected
capability. It never acquires/copies/retains/releases PNG bytes, builds packs during
discovery or seeds all 30 artworks. Construction asks the real owner for only the
selected complete prefix. `forAuthoringAttempt` belongs to later real preparation.

Pending preparation cancellation needs an optional SAME-session helper. C1 is busy
with no retained review during prepare: `service.cancel(reviewToken)` and
`workbench.discardDraft()` cannot cancel it. The helper must recognize the original
request/connection and use the existing generation, AbortSignal and cleanup escrow.
Missing helper projects Cancel unavailable. Unknown acceptance retains resources
and original ID for recovery, never unadopted cleanup. No eighth service verb or
new meaning for cancel tokens is added.

Borrowed callbacks are fenced by complete source, connection and published-version
checks including ABA. There is no new executor, history, hash, catalogue, raycaster
or resource owner. Component/data checks do not prove Host Apply, native rendering,
owned editing-meter enforcement or WAL adoption.
