# Original Nautilus fantasy equipment

Original mesh designs and deterministic native-metre construction: Nautilus Artist, 26 November 2026. Original painted material master: built-in imagegen, with exact prompt and unchanged source PNG retained in `source/`. The deterministic atlas packer resizes and quantizes that master; it does not generate substitute noise or borrow outside artwork. Geometry, sources and adaptations are authored for this Nautilus project. No new third-party art, model or texture license is introduced by this kit.

The code requires a host-supplied Three namespace and contains no Three copy. Existing native goat geometry/paint is used only by the review viewer through the engine's native-actor API. It retains the repository's existing source pin `781246a668c723d5a4c5463e70534cc04b6a5641` and notices; that review reference is not embedded into equipment runtime or imported anew. Sharp and Playwright are authoring/review dependencies, not runtime dependencies.

Provenance hashes and reproducible source paths are in `provenance.json`. Art sockets and collision-like visual bounds convey no authority to hit, block, spend resources or launch a game projectile.
