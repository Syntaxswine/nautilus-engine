# Tile kernel provenance

The bounded headless tile kernel is engine-owned code. Its alignment design and
conformance research use the already reviewed AFT snapshot
`781246a668c723d5a4c5463e70534cc04b6a5641`: block connection/feature/rotation rules
and the shore/cliff shared-field and patch-welding principles. Original upstream
bytes remain in the existing `vendor/aft/` snapshot, separate from this adapter.
Existing project/upstream notices continue to apply. No new donor import or
runtime renderer is included here.

`docs/reviews/procedural-tiles/source-audit.json` records exact original hashes,
the unchanged newer AFT Git-object comparison and historical test-only references.
The historical repository is research evidence, not a new approved runtime pin.
Scalar/cubic/arc formulas and canonical boundary/planning policies here are
versioned engine data/math. They do not grant a game physics, traversal, support,
navigation or fire capability. Painterly skins and family mesh/query providers
are separate reviewed contributions.
